# 破天宗 · 修仙模拟

依据《破天宗修仙模拟器 游戏设计开发文档 V1.3》实现的网页版修仙模拟经营游戏。
纯静态前端（无构建步骤）+ WorkBuddy 云服务（账号、存档、榜单、兑换码）。

## 玩法概要

- **身份与修为分离**：杂役以九星标识身份，正式弟子以九步标识；境界共二十阶，与步数多对一映射。
- **跃迁有阻力**：前三步随时间自然晋级；第三步晋第四步为批次竞争考核（最多四成通过、每人三次机会）；第四步之后按递减通过率判定；第九步亲传弟子只能由祖师指定。
- **经营闭环**：招收 → 修炼 → 突破 → 生产 → 任务与派遣 → 反哺招收。
- **四幕主线 + 十六个关键事件**，选择写入宗门史且不可撤销；终局三种结局。
- **三机构九席位**：弟子阁、护法堂、长老会，竞选按八维加权排序。
- **大世界与对战**：三方势力外交、派遣探索、邀约制对战、赛季榜单。

## 账号体系

**站点不提供手机号、邮箱等自助注册入口。** 登录页只有「账号 + 口令」，玩家账号一律由管理员在管理台开立。

- 初始管理员：`admin` / `Potian@2026`（已由数据库自动注册，首次登录后请在「设置 → 修改口令」中更换）。
- 管理员登录后，「宗门总览」「设置」与存档页都会出现**管理台**入口。
- 管理台可：开立玩家/管理员账号、重置口令、停用/启用、删除（连同存档）、发放与停用兑换码。
- 口令以服务端加盐 + 1500 轮散列存储，数据库与接口都不回传明文；客户端只持有 64 位会话令牌（30 天有效）。
- 停用账号立即踢下线（会话删除），存档保留；删除账号会一并清除其存档与榜单记录，不可撤销。

```
js/cloud.js         云服务：登录、存档、榜单、兑换码、管理接口
js/admin.js         管理台（开号 / 重置 / 停启 / 发码）

```

## 本地运行

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

账号走自建接口，不依赖 OAuth 回调，因此在 localhost 也能正常登录与存取档。

## 云端结构

| 表 / 函数 | 用途 | 访问策略 |
| --- | --- | --- |
| `accounts` | 账号、角色、状态、加盐散列口令 | 无客户端权限，只经函数 |
| `sessions` | 会话令牌（30 天过期） | 同上 |
| `saves` | 每账号三份独立存档，含修订号与完整快照 | 同上，按令牌归属过滤 |
| `rankings` | 赛季榜单公开字段 | 同上 |
| `redeem_codes` / `redeem_logs` | 兑换码与核销记录 | 同上 |

所有读写都经 `SECURITY DEFINER` 函数（`account_login` / `save_put` / `rank_top` / `redeem_code` / `admin_*`），
表本身对匿名与登录角色一律 `REVOKE`，客户端拿不到任何表结构，也读不到码表与他人存档。
存档写入带修订号校验：多端并发时旧版本会被拒绝并提示刷新。
